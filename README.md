# ⌨️ Typing Game

A simple typing game built with javascript.

## 📄 Tech Stack
- `Javascript`
- `HTML`
- `CSS`

## ✨ Features
- **Scoring System**: Every correct letter give 100 points.
- **Score Decay**: Every second your score decreases by 10% of your current score.
- **Mobile Mode**: Allows mobile compatibility.
